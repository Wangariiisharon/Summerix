SaaS Starter Kit 🚀

Modern and scalable SaaS Starter Kit designed to jumpstart your product development. This boilerplate comes wih certain important feature out of the box so that you dont have to write the boilerplate code, instead you could focus on building the core feature!

✨ Features

✅ Authentication

Secure sign up, log in, and log out with Firebase Authentication.

🔐 Permission System

Fine-grained access control for different users and features.

👥 Role based Access Control (RBAC)

Structure roles like Admin, Manager, User etc. with separate abilities.

🛂 User Permissions

Assign specific permissions at the individual user level for maximum flexibility.

🏢 Permissions by Department

Create users under departments and manage access based on the role for that department.

📊 Dashboard

Customized admin/user dashboard that shows main statistics and data insights.

💱 Currency Support

Multicurrency is supported in any configuration and visualisation.
